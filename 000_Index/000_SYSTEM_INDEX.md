# 000_SYSTEM_INDEX

This file acts as the primary map for the Obsidianman Vault. Every folder outside of this exact taxonomy should not be considered part of the core Obsidian architecture or the graphify mapping process.

## 🗂️ Taxonomy and Folder Structure

- **`000_Index`**
  For all navigation information in Obsidian and inside the vault (e.g., Graphify outputs, dashboards, and any other system map).

- **`001_Proyects`**
  All active projects currently in development.

- **`002_Workflow_Ideas`**
  Used for conceptualizing workflows and flowcharts, utilizing tools like Excalidraw mainly for n8n logic.

- **`003_Wiki`**
  The Personal Diary and Atlas of local information. This is where personal thoughts and curated knowledge live.

- **`004_Files`**
  All projects considered by the Operator as finished or no longer of interest. If a project is here, the Navi assumes it is completed or abandoned. However, elements and assets from these projects can still be referenced or salvaged for new projects.
