# Credits & Acknowledgements 🏆

The NetNavi OS Dual-Brain Architecture is only possible thanks to the incredible open-source projects, APIs, and conceptual models built by the community.

## Foundational Technologies & Skills
- **Antigravity Action Layer** - Orchestration and governance.
- **Obsidian** (`obsidian.md`) - The vault UI and primary database.
- **Graphify** - For converting local data into dynamic `.gexf` graph networks.
- **Gephi** - Network visualization and analysis.
- **Gemini CLI** (`@google/gemini-cli`) - The terminal action execution layer.
- **Node.js & Python** - Core scripting runtimes.
- **Google NotebookLM** - Cloud-based deep research learning.
- **Pinecone API** - Vector memory storage for the "Ghost".
- **n8n** - Air-gapped automation workflows.
