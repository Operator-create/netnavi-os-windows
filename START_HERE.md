# 👋 Welcome to NetNavi OS — Start Here!

> You do not need to know how to code. Pick the option that fits you.

---

## ⚡ Option A — Instant Boot (No Terminal Required)

This gets you 80% of the NetNavi experience in under 5 minutes. No scripts, no terminal, no technical knowledge required.

### What you need:
- [**Obsidian**](https://obsidian.md) — free download
- [**Antigravity**](https://antigravity.google/) — free AI assistant *(recommended)* or [Claude](https://claude.ai) / any AI that can read files in a folder

---

### Step 1 — Open the Vault in Obsidian

1. Download this repository as a `.zip` (click the green **Code** button → **Download ZIP**).
2. Unzip the folder anywhere on your computer.
3. Open **Obsidian** → click **"Open folder as vault"** → select the unzipped `NetNavi-OS-Windows` folder.

---

### Step 2 — Connect Your AI to the Folder

Open **Antigravity** (or your chosen AI) and point it at the same `NetNavi-OS-Windows` folder as your workspace. This allows it to read the `CLAUDE.md` file — which is your Navi's brain.

---

### Step 3 — Paste This Into the Chat and Press Enter

```
I have downloaded the NetNavi OS vault. Please open and read the CLAUDE.md 
file in this folder.

Use it as your core directive — you are now my NetNavi.

Once you have read it, begin the Awakening protocol: ask me what name I want 
to give my Navi, introduce yourself according to the lore, and guide me 
through setting up my Ghost.
```

Your Navi will take it from there. 🌐

---

### Step 4 — Give Your Navi Long-Term Memory (Optional)

Get a free API key at **https://pinecone.io** and tell your Navi:

```
My Pinecone API key is: [paste your key here]
Please save it and activate your long-term memory.
```

## 🔧 Option B — Full Installation (Unlocks the Action Layer)

This installs the full power stack: Python scripts, Gemini CLI, the Semantic Firewall engine, and all automation capabilities.

**Use this if you want:**
- The automated `semantic_firewall.py` running on your data
- Gemini CLI terminal action layer
- n8n automation workflows
- Full pipeline runner and memory sync scripts

### Steps:
1. **Double-click** `▶ INSTALL ME FIRST.bat` — installs all dependencies automatically.
   > If Windows asks "Do you want to allow this app to make changes?" — click **Yes**.
2. **Double-click** `setup_keys.bat` — saves your Pinecone API key.
3. Open **Obsidian** → *Open folder as vault* → select the `NetNavi-OS-Windows` folder.
4. Connect your AI (Antigravity/Claude/Gemini) to the folder.
5. Paste the Option A prompt above to begin the Awakening.

> ✅ You can start with Option A today and upgrade to Option B later — they are fully compatible.

---

## ❓ Something went wrong?

- Make sure you opened the **folder** as a vault in Obsidian, not a single file.
- If the AI says it cannot read `CLAUDE.md`, make sure the AI workspace is pointed at the same folder.
- Check `README.md` for more details on each component.
